# NekaID Claude Code Instructions

NekaID is a UK construction workforce verification and site management app.

## Tech stack
- Next.js App Router
- TypeScript
- Supabase
- Vercel
- Custom CSS only
- No Tailwind

## Critical rules
- Investigate first. Do not edit immediately.
- Explain the problem, file involved, and safest fix before changing code.
- Make small targeted changes only.
- Do not redesign working UI.
- Do not remove working logic.
- Preserve QR, PDF, auth, Supabase, attendance, induction, and worker verification features.
- Mobile-first for worker pages.
- Desktop-first for company dashboard.
- Never rewrite large files unless explicitly approved.
- If unsure, ask before editing.

## Workflow
1. Read the real files.
2. Explain the cause.
3. Propose the smallest safe fix.
4. Wait for approval.
5. Edit only approved files.
6. After editing, check for TypeScript/build errors where possible.
